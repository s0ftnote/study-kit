# 思维导图

导图是学科总览的另一种看法：总览是它的唯一来源，导图随时可以删掉重新生成。要改导图的内容，改总览。

命令里的 `<skill目录>` 换成本 SKILL.md 所在目录的绝对路径。命令写成一行，路径用双引号。

## 知识结构导图（默认）

用本 skill 自带的脚本从总览生成 Obsidian 的 `.canvas` 白板。不用装插件，节点里的知识点是链接，点一下就打开那页笔记。

```sh
node "<skill目录>/scripts/mindmap.mjs" --overview "<学习库>/知识/<学科>/<学科>总览.md" --out "<学习库>/知识/<学科>/<学科>导图.canvas"
```

脚本读总览里的二级标题（章节）、三级标题（专题）和列表里的第一个 `[[链接]]`（知识点），`来源` 一节不进导图。成功时打印一行 JSON，里面有 `ok` 和知识点数。

**完成标准：**脚本打印出 `ok`；告诉学生导图在哪，在 Obsidian 里点开就能看。第一次生成时在 `首页.md` 加一行 `[[<学科>导图.canvas]]`（链到白板要带扩展名）。

坐标由脚本算，不手写 `.canvas`。学生在白板上拖动过节点、想保留自己的摆法，就另存一份他自己的，自动生成的那份照常覆盖。

## 薄弱点导图

学生想看“哪里还不行”时，加上进度表。脚本只画练过的知识点：要重温是橙色，会了是绿色，没练过的不画。

```sh
node "<skill目录>/scripts/mindmap.mjs" --overview "<学习库>/知识/<学科>/<学科>总览.md" --progress "<学习库>/练习/进度.md" --out "<学习库>/练习/<学科>薄弱点.canvas"
```

这张图带着个人掌握情况，所以放在 `练习/` 下。输出里的 `unmatched` 列的是进度表里有、总览里找不到的名字，多半是改名后漏改了链接，有就告诉学生。

## 别的图

- **一节课的讲解顺序图**属于那份资料自己，学生要的时候由 `bili-reach` 的课程结构图生成，不放进知识结构导图。
- **知识点之间的关系**已经写在各页的“相关”里，Obsidian 自带的关系图谱可以直接看，不用另画。
