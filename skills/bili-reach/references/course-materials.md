# 来源内整理：按请求范围写待审资料

仅在用户要资料页、主题导航、例题/板书定位、疑点或课程结构图，并已有可读材料时加载。只取稿或截图不进入本分支；这里只处理本次来源，跨来源去重与关联留给[入库交接](<wiki.md>)。

这是 agent 读证据后的工作，不是 CLI 的新命令。CLI 的待审入口只含来源、实际材料链接和待审状态，不要求查全库，也不预填空栏目。

## 整理流程

1. **定范围与位置。** 读取清单、已有待审稿及请求相关证据。需要落盘时按需创建或更新本次材料目录的 `review.md`；已有人工内容用针对性补充，不整页覆盖。用户材料没有 run 目录时，使用已授权的私有待审位置；只有阅读权限则直接交付草案。**完成标准：**本次是局部还是整课、来源与版本、证据位置和写入边界明确，缺项标未知；原稿、图片、清单与成功指针保持不变。
2. **按范围读证据。** 局部请求只读相关转写或画面并记录实际范围。用户明确要整节课资料页时，才分批读完所选 P 的全部可用转写并检查衔接；数字、公式、图形或题目需查看对应画面。只有截图的 run 没有 transcript，只描述实际查看的帧，不概括整课。**完成标准：**每项描述对应实际读过的片段或帧，已看/未看可区分，未读内容不被写成老师原讲。
3. **按需组织。** 从下方内容中只选本次请求且有证据的部分；时间取自转写或截图，不按文章长度猜，也不为凑资料包扩写。**完成标准：**所写主题、例题或画面说明能定位到现有材料及原片；题目条件/图形不全就只标候选位置，不补造内容。
4. **核对与交付。** 区分讲师原意、AI 归纳和额外补充，检查引用、数字、符号与条件。保留关键来源、实际已读范围和具体疑点；有疑点就写对应位置、缺什么及如何核对。**完成标准：**实质性描述有证据，人工内容保留，交付标为待审并说明未核对范围；是否落盘、写在何处清楚，若要入库再走交接。

## 有内容才设分区

来源和实际阅读范围可放在开头一两段，不必做成大表：保留原片链接、已知 BV/cid/P、runId（若有）、实际材料链接、字幕/ASR 或仅截图的来源类型，以及本次读过的时间段或查看的帧。用户材料缺元数据就标未知，不猜作者或 cid；待审状态保留。

其余分区按请求和证据选择，不留“本次未确认”“AI 补充：无”之类占位栏目：

| 可选内容 | 有内容时写什么 |
| --- | --- |
| **课程导航** | 相关主题、实际时间范围、所选 P 的原片回链及证据位置；短摘录与归纳分清身份。只要局部导航就不整理整课。 |
| **例题、板书或画面说明** | 候选标签、片段或帧的位置、实际查看的图片链接、条件/图形是否完整。只定位来源内材料，不创建主库正式题目。 |
| **疑点与材料缺口** | 具体数字、符号、术语、条件或未读/未看范围，对应时间与核对动作；补取失败如实记录。 |
| **AI 补充** | 用户需要且确有补充时才写，说明不是讲师原话，并给依据或推导；原稿保持不变。 |

### 证据定位

- 保留来源身份与 runId（若有），文件链接从资料页位置解析后可找到材料。
- 转写主题/例题使用实际分段的 `[start, end]` 秒数、转写文件位置与必要截图；单帧只写该帧秒数，不能由一个时间点推断整题范围。
- 原片回链在该 P 的规范 URL 上保留 `p` 并追加 `t`。缺链接或时间轴的用户材料只引用现有文件位置，并说明定位限制。

`coverage` 首尾时间不是内容完整率。区分“读完现有转写”“看过哪些画面”和“取得原课全部信息”；不能证明的范围保留为限制。教师讲的常见错误不是这个孩子犯错或不会的证据。

## 按需课程结构图

只有用户需要时才从已核对导航派生，可在待审 Markdown 用 Mermaid 表示；每个内容节点能映射到实际时间证据，删掉图后文本仍可使用。

**完成标准：**图只展示本次来源实际的讲解组织，不把先后顺序当作知识前置依赖，不生成跨课知识地图或个人薄弱点图；无需额外绘图服务。不能预览时注明“图形未预览”，不声称已验证渲染。
