# 课程笔记与导航

用户要课程笔记、主题导航、例题整理或课程结构图时加载。按主流程完成相应范围的读稿与看图，再组织本次来源的内容；跨来源整理走[入库交接](<wiki.md>)。

## 整理流程

1. **选取内容。** 按请求从下表选有实际依据的内容，沿用本次读稿和看图结果；题目条件仍不全时，保留候选位置与具体缺口。**完成标准：**每项内容来自实际读过的片段或看过的帧，范围与本次请求一致。
2. **保留定位。** 用实际时间段关联主题、方法或例题，关键画面附截图。区分老师原讲、自己的归纳或推导与未核对内容。**完成标准：**关键结论能找到对应材料和原片位置，具体疑点可回查。
3. **按请求交付。** 导航或提纲可直接在对话中给出。用户要求保存时，在本次私有材料目录按需创建或更新 `review.md`；已有人工内容用针对性补充。用户提供的材料没有 run 目录时，使用其授权的笔记位置。需要人工审阅或准备入库的稿件标为待审。**完成标准：**交付形式符合请求；若写入文件，位置明确且人工内容保留。

## 有内容才设分区

| 可选内容 | 有内容时写什么 |
| --- | --- |
| **课程导航** | 相关主题、实际时间范围和原片回链；只要局部导航就整理相关部分。 |
| **例题与板书** | 已核对的题目条件、画面说明、讲解步骤、片段位置与必要截图；条件不全时保留候选位置。 |
| **疑点与材料缺口** | 具体数字、符号、术语、条件或缺失范围，附对应位置与核对办法。 |
| **补充解释** | 按需要给出推导或补充，说明与老师原讲的区别，原稿保持不变。 |

## 证据定位

- 面向读者保留原片、所选 P、实际时间和必要的材料链接。BV/cid、runId、处理配置等从清单回查，正文只呈现理解和核对所需的信息。
- 主题与例题使用转写分段的实际 `[start, end]` 秒数。单帧只代表该时刻，整题范围由实际读过的讲解与画面确定。
- 原片回链在所选 P 的规范 URL 上保留 `p` 并追加 `t`。用户材料缺链接或时间轴时，引用现有位置并说明定位限制。
- 保存的笔记保留来源版本、证据链接和具体疑点；原稿、图片、清单与成功指针保持原样。`coverage` 首尾时间只作定位，实际阅读范围与画面核对范围分别说明。

## 按需课程结构图

用户需要时，从已核对导航派生简洁的 Mermaid 图；节点能映射到实际时间证据，文本可独立阅读。

**完成标准：**图展示本次课程的讲解组织，各节点可回查对应片段；交付时说明预览结果。
